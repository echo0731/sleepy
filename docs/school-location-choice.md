# 系统定位弹窗与速度优化

本版去掉App自己的“Choose location accuracy”提示框。打开教务直连学校页时不申请权限、不读取位置。用户点击“定位”后，未授权时才同时请求ACCESS_COARSE_LOCATION与ACCESS_FINE_LOCATION。Android 12+由系统弹窗提供精准/大致选择，选择并允许后读取位置。参见[Android官方定位权限说明](https://developer.android.com/develop/sensors-and-location/location/permissions/runtime)。

## 授权决定策略

SchoolLocationPolicy.modeForPermissions根据实际授权决定：coarse/fine俱全→精准策略，只有coarse→模糊策略，没有定位权限→权限拒绝。系统只授予大致位置是有效选择，不能按精准定位失败处理，也不再要求通过App弹窗重选。

用户点击定位且已有权限时直接定位；通常无法强制让系统再次弹出已经授予的权限。重新定位沿用系统当前精度；推荐框底部提供定位权限设置入口，与“查看全部同城学校/收起学校”并排；空间不足或大字体时自动换行。需要切换时在系统中调整，返回后不会自动读取位置，点击重新定位才使用新的授权。多次拒绝后系统可能不再弹框，可进入权限设置。参考[Android运行时权限说明](https://developer.android.com/training/permissions/requesting)。

没有页面进入时自动定位的LaunchedEffect，不论是否已授权，打开页面、旋转、从教务页返回或进程恢复都不会自行申请权限或读取位置。退出页面/进入后台取消位置请求。点击“定位权限设置”只打开设置，返回后仍需主动点击定位；只有用户点击定位发现系统定位关闭，并通过该按钮打开定位总开关设置时，返回才继续这次已发起的定位请求。

## 速度与准确性

继续使用上版已验证的并行获取：可用提供者同时请求，边界索引在工作线程同时准备，有合格近期缓存可直接判断，取得合格结果后取消剩余请求。不再有GPS优先等待8秒，也没有模拟器专用刷新分支。

位置年龄最多30秒，不是需要等待30秒；超过、未来时间、非法坐标、无精度等均不能抢先成为推荐。精准策略精度半径上限1000米，模糊策略10000米。模糊策略不直接请求GPS，城市判断用0.01度取整坐标，并增加800米不确定性。

八方向采样检查周边城市归属，跨城或精度不够时不强行推荐，提示重新定位或到系统权限设置调整精度。采样用于降低误判，不是绝对保证；当地边界数据和系统位置误差仍会影响判断。边界解析在进程内缓存，一次请求设置12秒超时保护。

坐标不存数据库、设置或日志；城市与学校匹配保持本地执行，没有新增Geocoder/Google城市服务、地图SDK、API Key或后台定位。

## 验证

SchoolLocationPolicyTest覆盖系统授予精准、大致、拒绝时的模式映射，以及位置年龄、精度、坐标合法性、模糊取整和边界检查；SchoolLocationLookupTest保留并行获取、快来源返回、不让低精度结果抢占、模糊策略不请求GPS、取消剩余任务等验证。所有学校城市覆盖和新增学校动态检查保留。

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:assembleDebug :app:lintDebug
```

构建与测试结果详见交付报告及school-manual-location-build.log。没有实机时不能声称验证了新的系统弹窗或每次1秒完成GPS；用户之前提供的截图不能作为本版验收。真实手机验收应检查未授权和已授权时打开页面都不弹框/不定位；点击定位后才触发权限或查询，精准/大致都沿用系统授权；权限设置返回不自动定位；定位总开关设置返回继续已发起请求；按钮在推荐列表底部并排，展开后仍在列表底部。
