# 教务直连：可能的学校

## 功能

入口：课表管理 → 导入课表/作息表 → 教务直连。

学校选择页最前面显示一个标题为「可能的学校」的描边卡片。打开页面时不自动定位，用户点击“定位”后才按需申请系统权限，在系统弹窗中选择并允许后，按实际授权读取一次当前位置，通过本地城市边界匹配中文城市名，再用本地学校城市表匹配同城学校。城市识别不调用系统 Geocoder 或 Google 城市服务。

卡片先展示 5 个学校入口，可展开全部同城学校；“定位权限设置”在列表底部与展开/收起按钮并排，宽度不足或大字体时自动换行；已支持导入的学校优先，其余按完整拼音排序。点击推荐学校仍使用原来的 `onSchoolSelected` 回调，教务网址、协议、待适配提示及导入流程保持原有行为。搜索时隐藏推荐卡，完整目录、拼音/别名搜索、自定义教务链接和字母索引仍可使用。

这里的「附近」按**同城**定义，不按校园距离排序。全国高校名单中的所在地作为基础，再用学校官网核实的实际教学地点和异地校区覆盖或补充。多个城市可以对应同一学校入口；独立学院和单列分校入口分别核查，不自动继承母校城市。不能靠学校名或地址中某条路的名字推测城市。已核查的特殊情况见 [学校城市核查说明](school-city-audit.md)；这不是完整的全国分校区地理数据库。

## 定位与降级（当前版本）

- App不再显示自行制作的“选择定位方式”弹窗。只有用户点击定位且未授权时才调用系统权限请求，同时申请coarse/fine；Android 12+的系统弹窗提供精准/大致位置选择。更早系统不一定有精度切换项。
- 系统授予fine与coarse时使用精准策略；仅coarse时直接使用模糊策略，不再提示“未获得精准权限”。拒绝权限时保留学校搜索和定位权限设置入口。
- 用户点击定位且已有定位权限时直接定位；Android通常不会为已授权权限再次弹窗。重新定位沿用当前授权，不重复强迫用户升级权限。需要切换精度时点击“定位权限设置”，在系统中调整后返回不会自动定位，主动点击重新定位后才读取实际授权和位置。
- 打开页面、旋转、从教务页返回和进程恢复不会自动请求权限或位置；已完成城市结果可保留。普通前台恢复与权限设置返回不自动定位。只有点击定位后发现系统定位关闭，并打开定位总开关设置时，返回会继续这次用户已发起的请求。
- 使用现有LocationManagerCompat并行请求可用来源；精准策略包含GPS，模糊策略排除直接GPS请求。没有模拟器专用GPS优先8秒等待。
- 30秒以内、坐标合法且精度有效的位置可直接参与判断；精准策略精度半径上限1000米，模糊策略10000米。这是位置年龄上限，不是等待30秒。
- 模糊坐标取0.01度，并给误差半径额外加800米。根据精度半径在八个方向采样，中心与周边不属于同一城市时继续尝试其他结果或提示调整精度，降低交界处误判。采样不保证整个误差圆内的真实位置绝对准确。
- 边界首次加载在工作线程进行，并与位置请求并行；进程内缓存可复用。一次请求有12秒超时保护，离页、进入后台或取得结果后取消剩余请求；不申请后台权限。
- 城市和学校匹配在本地完成，不调用Geocoder或Google城市服务，不新增地图SDK/API Key。经纬度不写数据库、设置、日志；手机系统定位来源能否工作及是否用网络取决于设备实现。

详细流程与系统权限行为见 [系统定位弹窗与速度优化](school-location-choice.md)。

## 数据及来源

`app/src/main/assets/school_cities.json` 为独立的城市索引，覆盖当前 `schools.json` 的 348 个入口。加载失败时仍正常加载原学校目录。

主要来源为教育部《全国普通高等学校名单（截至2026年6月17日）》：

https://www.moe.gov.cn/jyb_xxgk/s5743/s5744/202606/W020260618416094865984.xls

原始 XLS 的 SHA-256：`29c40f083b639888e429cf40b68f9a75782d1ce81131c99aabca65b65b36eaea`。检索/下载日期：2026-10-05。

317 个目录名称与官方名单精确匹配。另有 27 个旧校名、附带研究生/登录方式的名称通过 `_nameMappings` 显式对应；四个分校或补充条目在 `_supplements` 中记录城市和官方来源。2026-10-06 对多城市校区、迁址及县级城市等情况追加核查，`_campusOverrides` 保存学校官网来源、城市数组和处理原因，数据整理时将核实结果同步写入对应的学校和显式别名的 `schools` 城市数组；运行时不读取这些核查元数据。原目录中的名称、URL、协议未由城市索引修改。

`schools` 下的键必须与学校目录名称完全一致，值为非空城市数组，例如：

```json
"广东东软学院": ["佛山市"],
"东北大学秦皇岛分校": ["秦皇岛市"]
```

后续增加学校时同时补齐城市，字段模板与检查命令见 [新增学校规范](adding-school-city.md)。`SchoolCityIndexTest` 动态检查目录覆盖、重复名称、城市数组和全部入口的推荐；`OfflineSchoolCityIndexTest` 检查城市在离线边界表中的覆盖。核查元数据仅记录依据，运行时读取的是 `schools` 下的最终数组，修改校区依据后必须同步更新此数组。

## 当前版本手动验收

1. 在真实手机的新安装或尚未授权的应用中进入教务直连；应显示“点击定位”提示，不自动弹权限框或读取位置。已授权的手机打开页面也不自动定位。
2. 主动点击“定位”，未授权时才显示系统权限弹窗；选择精准并允许后，确认取得城市、学校推荐及教务入口；另一个未授权会话点击定位并选择大致后使用模糊策略。
3. 已授权时点击定位/重新定位后才查询位置。更改精度可使用推荐框底部的“定位权限设置”，在系统中调整后返回不自动定位，点击定位才读取新权限；系统是否重启进程由Android/OEM决定。
4. 拒绝权限、关闭定位、精度不足及定位期间离页等场景，检查提示、搜索保留及请求取消；多次拒绝导致系统不再弹窗时可使用权限设置入口。
5. 核对“查看全部同城学校/收起学校”和“定位权限设置”在列表底部并排，大字体或窄屏时可换行；没有展开按钮时权限设置独立显示。检查拼音/别名搜索、网址搜索、字母索引和学校点击导入。

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:assembleDebug :app:lintDebug
```

历史模拟器记录描述的是早期GPS修复版，旧的GPS优先监听、虚拟坐标刷新步骤和App选择弹窗都不属于当前版本。

## 定位失败修复（2026-10-06）

旧实现依赖系统 Geocoder。在用户的 Android Studio 模拟器上已复现：GPS 获得国内虚拟坐标，但 GmsGeocoder 报 reverse geocoding network failure，界面超时后显示 City unavailable。

新版移除 Geocoder 调用，国内城市在本地识别。`app/src/main/assets/school_city_boundaries.json.gz` 来自 [zhChuXiao/ChinaGeoJson](https://github.com/zhChuXiao/ChinaGeoJson)，MIT 许可证，上游提交 `7aa2c5fabc6a892015625898c3482874b233f9de`，下载日期 2026-10-05。包含 34 个省级数据文件中的 476 个多边形条目，覆盖 370 个城市或直辖县级区域名称；直辖市和港澳区级数据统一归到城市名称。保留完整环坐标，压缩为 gzip，不做按距离猜测。原始文件路径与 SHA-256 存于数据的 `_source.originals`。

许可证全文随 APK 打包到 `assets/third_party/ChinaGeoJson-LICENSE.txt`，并在「关于 → 开源许可与致谢」正文中保留版权与许可文字。边界数据是该开源项目的快照，可能受边界简化、坐标基准与行政区调整影响；它用于辅助找学校，边界附近的大致定位可能匹配到相邻城市，完整搜索始终可用。

模拟器不会读取 Windows 电脑的现实位置。测试时在模拟器工具栏 **… → Location** 设置国内经纬度并点击 **Send / Set location**，随后在 App 点击 **Locate again / 重新定位**。城市结果短时缓存，改变虚拟定位后应主动点重新定位刷新。默认的美国虚拟坐标不会被强行匹配到中国城市。

打包验收还发现 AAPT 会自动解压源码中的 `.gz` 资产并去掉后缀。因此源码保留 `school_city_boundaries.json.gz`，运行时必须读取 APK 中的 `school_city_boundaries.json`，不能再次按 gzip 解压。该路径已通过实际 APK 内容检查；后续修改数据打包方式时应同时检查运行时文件名。

模拟器实测还发现：大致位置请求在该 Android 37 实例被系统限制为 LOW_POWER、10 分钟最小更新间隔，GPS 不产生新结果。因此新增可选的前台精确位置授权，处理 GPS-only 设备的刷新；拒绝精确授权时保留已有大致位置能力及完整学校搜索。

城市切换验收发现，系统的 current-location API 和最近位置缓存都可能继续返回旧位置；模拟器 GPS 关闭时新注入坐标也不会更新系统缓存。因此精确权限路径改为一次短时 GPS 监听，取得新样本后立即移除，取消或离页时也移除；不是持续或后台定位。

定位修复版验收（2026-10-06，追加学校城市核查前）：2454 项 Debug 单元测试全部通过，assembleDebug 与 lintDebug 成功（Lint 0 错误、497 警告、27 提示）。Android 37 / Pixel_10_Pro 只读测试实例在 Wi-Fi 与移动数据关闭、前台精确权限已授权时，惠州坐标显示惠州学院；切换佛山并点击重新定位后显示广东东软学院；境外坐标显示未匹配城市；再切回惠州正常。APK 内边界 JSON 与源码 gzip 解压结果逐字节一致。测试实例中的应用安装不修改原 AVD 数据。实际权限弹窗各选项与真实手机位置服务仍需验收。
