# 学校城市核查说明（2026-10-06）

程序不会从校名中提取地名。学校城市表原先以教育部名单的“所在地”为基础，这避免了按名字猜城市，但可能漏掉异地校区，或继续沿用登记所在地而不是当前上课地点。

## 本次核查结果

- 对全部 **348 个教务入口**的基础来源重新逐项检查：317 个精确校名、27 个显式旧名或登录/研究生变体、4 个独立补充入口；没有来源字段抄录差异。
- 对 **45 所学校的特殊情况**进一步查阅学校官网、章程、校区页或招生材料，调整 **46 个目录入口**的城市数组（包括厦门大学的研究生入口）。每项原因与来源同时保存在 `school_cities.json` 的 `_campusOverrides` 中。
- 其中两项按当前教学地点修正：浙江工业大学之江学院从杭州改为绍兴；江西农业大学南昌商学院从南昌改为九江（学校在共青城，使用本地九江地级边界）。其余补充已核实的跨城市校区。
- 全部推荐城市在本地边界数据中都有对应名称；学校名、网址、协议、教务适配状态没有改动。

这次完成的是全部入口的**基础所在地对照**和下表列出的**特殊校区核查**，不等于全国每所大学全部教学点、异地研究院和最新搬迁的逐一穷尽盘点。未在下表中的入口继续使用已有基础来源；官网不可访问或没有充分证据时不猜测补入城市。校区变化仍需要以后按官网更新。历史章程与最新页面冲突时在原因中保留不确定性，不能据此宣称没有遗漏。

## 定位是怎样变成学校推荐的

1. Android 系统给 App 一对经纬度，相当于“你在地图上的这个点”。真机坐标由系统位置提供者取得；Android Studio 模拟器使用你在 Location 面板发送的虚拟坐标。
2. App 自带一份城市边界地图，相当于“每个城市在地图上的圈”。程序判断这个点落在哪个圈里，得到例如“佛山市”。这一步在本地完成，不调用 Google 的城市识别接口，也不用向外部服务发送坐标。
3. 查事先核对的学校城市表。例如华南师范大学写有广州、佛山、汕尾，只要当前城市在这三个城市之一，就把原来的学校入口放进“可能的学校”。只查表，不阅读校名猜位置。
4. 同城学校先显示在卡片里，已支持教务导入的入口优先，其余按拼音排列。不是按到校园的距离排序，也不能通过定位断定你就读哪所学校或哪套教务系统。

普通县级市和区统一归本地地图所使用的地级市，例如溧阳→常州、江阴→无锡、桐乡/海宁→嘉兴、安溪→泉州、峨眉山→乐山；直辖市各区统一归北京、上海、天津、重庆。湘西等自治州使用对应州名称。边界之外的点不强行猜一个国内城市。

城市边界数据是开源地图的静态快照，GPS、大致位置以及地图边界本身都可能有误差，尤其在两市交界处；仍可用完整搜索找到学校。校园数据库不是实时更新，定位系统获取坐标时是否联网取决于设备实现。本功能的**坐标转城市及学校匹配**两步均在本地完成。
